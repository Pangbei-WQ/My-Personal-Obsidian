# 十字路口对谈 Paperboy：Agent 的下一种形态——主动找你，而不是等你命令

## 一句话总结

**现有 Agent（Claude Code/Codex/Manus）都是"session-based + prompt-based"——每次对话重来、被动等你下指令。** Paperboy 的构想是：Agent 应该像你的微信联系人一样**主动找你**——它通过观察你如何使用电脑来学习，用"IM 式"对话而非"session 式"会话，自动推进任务。

---

## 嘉宾身份

**Paperboy**：CEO John Yang，21 岁，团队 12 人，融资 470 万美金。试图做出"主动型"AI Agent 的新锐团队。

---

## 核心内容

### 1. 现有 Agent 的缺陷

- 现有工具都是 **session-based（会话式）+ prompt-based（指令式）**：
  - 每次任务开一个新会话，**从零开始**，没有连续记忆
  - 永远**被动等待**用户下指令
- 结果：用户要不断"喂"上下文，Agent 无法主动推进

### 2. 新形态：观察式学习 + IM 式对话

- **从环境学习**：Agent 通过观察用户如何使用电脑（操作习惯、上下文、工作流）来自主学习，而不是只听指令
- **用 IM 而非 session**：像微信群聊一样——Agent 随时可以"发消息"给你，主动汇报、追问、推进
- 灵感：来自微信群聊的协作模式——人不是在一个个"session"里协作，而是在持续的关系流里

### 3. 按任务时长分层的交互

- "**1 秒内任务用 autocomplete**，几小时任务用 IM，更长周期仍是待探索区"
- 即：越短的任务越自动化（自动补全），中等任务用对话式协作，长期任务（跨天/跨周的项目）如何协作仍是空白

### 4. 行业判断

- "**人类和 AI Agent 的最佳配合方式，还没被发明**"——当前所有形态都只是过渡
- 这意味着：Agent 交互范式的创新空间还很大，是创业机会也是产品设计的开放问题

---

## 实操建议

1. **（产品人）关注 Agent 的"主动性"**：下一代 Agent 产品的差异点可能是"主动找你"而不是"等你命令"
2. **（用户）按任务时长选工具**：秒级任务用自动补全，小时级任务用对话式 Agent，长期项目主动关注新范式
3. **（创业者）"最佳配合方式还没被发明"**——这是少见的开放蓝海
4. **给 Agent 观察学习的权限时**：结合戴冠兰的"动态权限、用完即收"原则，避免过度授权
