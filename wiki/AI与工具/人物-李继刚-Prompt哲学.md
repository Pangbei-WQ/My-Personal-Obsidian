## 一句话总结

**写好 Prompt 的终极心法只有两个字：压缩。** 把一本书压成一个词，把这个词说给大模型，它就能展开整本书。**你脑子里的知识，决定你使用 AI 的上限——Read in. Prompt out.**

---

## 作者定位

- 国内 Prompt 领域几乎等同于代名词的人物：2024 年 8-11 月写出数百个流传各大社区的 Prompt（"公文笔杆子"刷屏），9 月"汉语新解"（SVG 卡片解词）再度爆火
- 从研究生起读书 13 年，从工具书/畅销书转向哲学后，速度降到**一个月一本**
- 长期 Emacs 用户（配置语言 Lisp），擅长把思想极致压缩成词

---

## 核心思想

### 1. 压缩：一本书讲一个词

- 哲学书往往用厚厚一本讲一个词，这个过程就是**压缩**
- 例：营销书《定位》整本 314 页只讲一个词——"如何占领用户心智"
- 跟大模型对话也能用一个词开启整个**解压**过程：跟 Claude 说"尼采的生命意志"，Claude 直接展开讨论
- **极致压缩的写法诞生了"汉语新解"**——核心不是 SVG 卡片，而是被压成几个词的文案：**隐喻、一针见血、辛辣讽刺、抓住本质**
- 新 Prompt"类比之弓"同样压成四个词：**本质内核、模式知觉、同构外推、精准概括**——都来自他读过的一本书

### 2. 为什么用 Lisp 写 Prompt

- Lisp 诞生于 1958 年，世界第二古老的语言，**专为 AI 而设计**
- 李继刚用十年 Emacs，虽然不会写 Lisp，但"看了 10 年，怎么也能学着跑两步"
- **真正核心不是语言，而是那几个被极致压缩的词**——翻译成 Markdown、Python 一样
- "真正重要的，永远是自己的思想。思想，决定一切。"

### 3. 对 Prompt 框架的批评

- 三字母/四字母框架（作者自己早年也写过 CRISPE）"跑偏了"
- 写 Prompt 的技巧性东西就那三五招：**指定角色、Few-shots 示例、CoT 思维链、情绪勒索**
- 本质是："**想象对面坐了一个人，我要塑造一个角色，让这个角色活过来，去做一个指定的动作**"
- 框架 = 学车的辅助小双轮，让你从 0 到 1 不翻车；但"当你越想跑起来，它越是个限制，只有扔掉它，才能天高任鸟飞"

### 4. Prompt Engineer = 编程思维 × 写作思维

- Prompt = 提示、表达（写作思维）；Engineer = 工程师（编程思维）
- 编程语言脉络：二进制 → 汇编 → C → C++/Java/Python，两条主线——①越来越接近自然语言，②程序员群体越来越大 → 推演下去**必然到自然语言编程：人人都是程序员，大模型就是编译器**
- 今年更感觉 Prompt 像写作：脑子里有东西需要压缩后清晰表达，讲究篇章布局
- **正确答案是两者的交集**：既要有理性数学的编程思维，又要有会写作的感性表达思维

---

## 实操建议

1. **多读书，读"讲透一个词"的书**——尤其哲学。工具书攒的是"工具箱"，困惑反而越来越多；哲学书才训练压缩能力
2. **写作 Prompt 时先压缩**：把要表达的核心压成 3-4 个词（隐喻/一针见血/抓住本质……），让模型去展开，而不是堆砌长指令
3. **扔掉框架**：从"塑造一个角色，让它做一个动作"出发，而不是套 CRISPE 之类模板
4. **双修编程与写作**：复盘身边写 Prompt 好的人，确实既懂编程、又常读书写作——两条腿走路
5. **以终为始**：他给自己画了 60 岁的终点，用 20 年留一句话——"只有给自己画一个终点，才能知止而后有定心"
