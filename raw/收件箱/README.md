# 📥 收件箱（Inbox）

所有待处理的原始素材统一入口。**只保留，不思考。**

> 本目录是"捕获端"的落地：素材先无摩擦地丢进来，整理交给 Claudian 在 ingest 时统一处理。

---

## 目录结构

| 子目录 | 用途 | 投递方式 |
|--------|------|---------|
| `链接/` | 网页 / 链接 / PDF | Obsidian Web Clipper、手机浏览器分享 |
| `语音/` | 语音转文字的灵感、口述想法 | 手机语音输入法（豆包/讯飞等）转文字后分享进来 |
| `杂项/` | 不属于以上两类的临时素材 | 直接丢 |

---

## 使用规则

1. **只管丢，不要整理**：任何想法、链接、录音随手丢进来即可，命名随意（建议 `日期-关键词`），整理交给 Claudian。
2. **处理时机**：每次打开 Claudian 会话，开场会自动扫描本目录，报告待处理数量。
3. **防囤积**：每周清理一次。处理完的移出或归档，避免堆积成"只进不出"的死水。

---

## 处理流程（Claudian ingest · 顺序严格）

收件箱只是**原文入口**，处理遵循固定顺序，**全部完成后才清空收件箱**：

```
① 扫描识别   → 识别每条素材的内容类型
② 提炼       → 提炼精华要点（后续写入 wiki）
③ 原文转 .md → 把原文规范化为 .md 文件
               （链接→抓正文；语音→转文字；PDF→抽文本；已是 md→规范化命名）
④ 归档 raw   → 按内容归入 raw/ 对应子目录（网页剪藏 / 知识文件归档 / 任职资格 等）
⑤ 建/更新 wiki + index → wiki 提炼页与 index 的 sources 指向 ④ 归档的 raw .md 存档
⑥ 清空收件箱 → 上述全部完成后，才清空本目录
```

**关键约束：**
- **先提炼 → 再转 .md → 再归档 raw → 最后才清空收件箱**，顺序不可颠倒。
- wiki 中提炼的精华、`index.md` 里指向的，是**归档到 `raw/` 的 .md 文件**，不是收件箱里的临时文件。
- 归档后收件箱应保持干净，不留孤儿文件。

---

## 归档去向（raw/ 对应子目录）

| 素材类型 | 归档位置 |
|---------|---------|
| 网页 / 文章 / 链接 | `raw/网页剪藏/` |
| 长文 / 文档 / 语音转录文本 | `raw/知识文件归档/` |
| 任职资格相关内容 | `raw/任职资格/` |
| 其他 | 按内容判断，归入最合适的 raw 子目录 |

> 提炼出的精华 → `wiki/` 对应领域页面（`sources` 指向上面归档的 raw .md 存档）。
