## 一句话总结

**前编导出身的博主 lala罐头 用 3 个 AI 工具——Gemini 当「AI 编导」、Nano Banana 当「AI 分镜师」、即梦 Seedance 2.0 当「AI 拍剪师」——搭出一套"零实拍"AI 广告短片工作流。** 核心思路是把创意拆成「脚本 → 分镜图 → 成片」三步标准动作，让每一步都有明确的输入和输出，从而让 AI 生成的视频**确定性更强、稳定性更高，适合商业场景批量复用**。

## 核心结构总览

| 角色 | 工具 | 职责 |
|------|------|------|
| AI 编导 | **Gemini**（+ 调教好的提示词） | 拆解卖点 → 输出分镜脚本（景别/运镜/主体动态/画面内容）→ 转九宫格生图 JSON 提示词 |
| AI 分镜师 | **Nano Banana Pro**（在 FlowFlow 平台） | 消化 JSON 文字 → 生成九宫格分镜图（结合产品参考图保一致性） |
| AI 拍剪师 | **即梦 Seedance 2.0** | 分镜图 + 产品图 → 按 1→9 顺序生成连贯视频 → 剪辑成片 |

**工作流比喻（像做汉堡）：** 烤好面包（定脚本）→ 煎好肉（定分镜图）→ 组装拼盘（剪辑成片）。每个环节按标准进行，才能保证每个"汉堡"稳定出炉。

## 主体内容

### 1. 为什么要"零实拍"

- 广告实拍**费钱、费时间、费精力**。博主自述做过最难的项目是给冰淇淋拍带货广告：要控制融化速度、挖出完美的球形、还要在有限预算里做出高级质感，非常困难。
- 现在只要三个工具（Gemini + Nano Banana + Seedance 2.0）就足以做出一条还不错的广告短片，且这套工作流**可复用**。

### 2. 第一步：Gemini 写脚本（AI 编导）

1. **投喂调教好的提示词**，让 Gemini 化身为"短视频脚本专家"，具备带货短视频编导的思路（完整提示词见视频粉丝群）。
2. **提供三项输入**：商品核心卖点 + 目标人群 + 视觉参考。
3. **Gemini 输出第一轮分镜脚本**，一步到位包含：
   - **分镜景别**：特写 / 中景 / 全景
   - **运镜**：快速推进 / 静止锁定 / 缓慢推进
   - **主体动态** + **具体画面内容**
4. **不满意可迭代修改**：例如分镜中出现"静止锁定"会显得呆板，可让 Gemini 删掉该描述、换成更强的动态感和节奏感。
5. **确认无误后**，让 Gemini 把脚本转为 **JSON 格式的九宫格生图分镜词**（英文图生提示词），复制即可交给下一步。

### 3. 第二步：Nano Banana 出分镜图（AI 分镜师）

1. 打开 **FlowFlow**（谷歌推出的 AI 创作平台，有免费多次的 **Nano Banana Pro** 和 **Nano Banana** 模型可用）。
2. **新建项目**，粘贴上一步的 JSON 提示词，**附上产品参考图**（确保生成的产品和实物一致）。
3. 生成设置选择 **Nano Banana Pro** 模型——虽然新出的 Nano Banana 2 强化了很多功能，但博主实测 **Pro 对复杂提示词的理解更好、更精准**。
4. 几秒后得到一张**九宫格分镜图**；不满意可以**多抽几次卡**。

### 4. 第三步：Seedance 2.0 视频化（AI 拍剪师）

1. 打开 **即梦** 视频模型，选择 **Seedance 2.0**，开启 **全能参考**。
2. 上传**分镜图**（参考图 1）+ **产品图**（参考图 2），确保产品一致性。
3. 把 Gemini 生成的脚本直接粘贴进去，按模板给指令：
   > 先基于分镜图图一，从 1 到 9 按顺序生成连贯的视频；产品参考图（参考图 2）确保产品的一致性。
4. 选择**尺寸 9:16**，**时长 15 秒**，点击生成。
   - 若排队太久，博主建议看其上一期视频找 Seedance 2.0 的**小众宝藏入口**。

**Demo 效果：** 猫粮广告整个画面保持很强的产品质感，吃猫粮的动作和音效非常生动，能很好地解决传统拍摄中"猫演员很难配合"的痛点。

### 5. Gemini 稳定输出的关键：三层提示词结构

写好提示词的**关键在于逻辑层级**：

| 层级 | 内容 | 作用 |
|------|------|------|
| **第 1 层：明确身份** | 让 Gemini 作为短视频专家，具备带货短视频编导的思路和产品挖掘能力 | "术业有专攻"，清楚身份后会聚焦核心技能 |
| **第 2 层：明确任务** | 分两步：① 先确认中文分镜脚本（镜头语言、内容画面等）；② 确认无误后，将中文提示词转为英文声图提示词，封装为标准 JSON 输出 | 方便批量、稳定地生成分镜图 |
| **第 3 层：锁定输出模板** | 把需要的格式细节全部写进提示词 | 让 AI 编导给到的就是你要的样子 |

### 6. 可复用的创意范围

掌握这套结构后，能做的远不止猫粮广告：

- 第一视角的农产品（现栽现发的"我子长得旺"，带着山里露水蜜粉、皮薄清香）
- 居家场景的模特展示
- 大牌美妆的产品特写
- 概念性的品牌广告片
- 彩蛋玩法：把 Gemini 人设改为**专业电影导演**，让"编导转行"出电影感短片

## 要点提炼

1. **工作流本质 = 把创意拆解成可执行的标准动作**：让 AI 在每一步都有明确的输入和输出（脚本 → 分镜图 → 成片），这是"确定性/稳定性"的来源。
2. **三工具分工明确**：Gemini 管"想"（编导）、Nano Banana 管"画"（分镜）、Seedance 2.0 管"拍剪"（视频化）。
3. **模型选型实测经验**：复杂提示词场景下，Nano Banana Pro 比新版 Nano Banana 2 理解更精准。
4. **产品一致性靠"双参考图"**：分镜图 + 产品图都喂给 Seedance 2.0，并开启全能参考。
5. **Gemini 稳定输出的关键是三层提示词**：身份 → 任务 → 输出模板，逐层锁定。
6. **商业价值**：解决传统广告实拍"猫演员难配合、预算高、周期长"等痛点，适合批量产出带货广告。
