## 主体内容

### 1. 文案创作：Claude 4.6

- 作者试过很多模型后回归 **Claude**，核心原因是**它写出来的「AI 味」最低**。
- GPT 写的东西句式、措辞一眼能看出"太机器"；Claude 的**语感更接近真人说话**，读起来舒服。
- 定位：长文写作 / 内容创作的首选。

### 2. 日常问答：GPT-5.5 + 豆包

- **国外用 GPT-5.5**：最大优点是**幻觉率低、回答可靠、出错概率小**；缺点是说话风格"有点干"、不讨喜，但日常够用。
- **国内用豆包**：又快又免费又够用。查概念、问定义这类**碎片化小问题不必开大模型**，豆包刚刚好。

### 3. 设计与开发

**设计 → Claude Design（今年新品）**

- 和"AI 生成图片"不同，Claude Design 是**真正懂设计**的视觉创作工具，第一版输出就好看——**排版、配色、布局都有审美**。
- 身边完全不懂设计的朋友用它做出来的东西**直接达到专业级**。

**代码 → Claude Code + 扣代（ASR 谐音，疑为 Codex）**

- 组合用法（作者原话概括）：
  1. 在 **Claude Code** 里用 **Opus**（ASR「oppos」）把需求抠清楚，产出**详细 plan**——想做什么、怎么做、边界在哪里全部理清；
  2. 把 plan 扔给 **扣代** 去执行。
- 分工逻辑：**Opus 的语言理解能力是另一个档次**，能把模糊想法变成结构化方案；**扣代执行效率更高**，拿着清晰 plan 跑，出活又快又准。
- 作者明确表示：**目前这个组合国内还没有平替**。

### 4. 信息转化：Get笔记 + 通义听悟

- **Get笔记**：两个典型用法——① 刷到好视频直接丢给它**提炼核心内容**，不必从头看完；② 开会时录音，结束直接生成**原文 + 会议纪要**，省大量时间。
- **通义听悟**（ASR「通一听务」）：专门处理**大文件**——大型会议录音、长视频，丢进去转写准确、理解到位，**完全免费**。

### 5. 图像生成：GPT Image + 分辨率补丁 + 即梦

- **GPT Image**（ASR「gT image」）：认真评价——**生成的质感很多时候比人工做的好**，公司申图基本都靠它。
- **唯一问题：分辨率**。需要更高分辨率输出的场景，用 **Nano Banana Pro**（ASR「banana pro」）来补。
- **国内平替：即梦**（ASR「极梦」），效果也很不错。

### 6. 知识沉淀：IMA + Obsidian

- **IMA**（ASR「作为IM」，腾讯知识库问答工具）：把 **PDF、文章、链接全部丢进去直接问问题**。它**只针对你上传的内容作答、不乱发挥**，所以幻觉率非常低、回答可靠。作者认为**这个产品被严重低估了**。
- **Obsidian**（ASR「ofC店」）：**所有笔记都在这里**。直接接入 Claude，**Markdown 格式对 AI 非常友好**；配合 **Web Clipper**（ASR「will clip」）一键收藏网页内容；花 **6 块钱**可开 **iCloud 同步**，手机、电脑都能用。

### 7. 效率工具：豆包输入法

- **实时语音转文字准确率极高**，且**完全免费**。
- 作者现在内容创作基本靠语音输入完成：整理思路、记录灵感、口述初稿，效率提升非常明显。
- 同类产品不少，但豆包输入法"打爆同类"，是作者用起来最顺手的。

### 8. 健康顾问：蚂蚁阿福

- **真的在用，不是广告**。身体不舒服不知道怎么回事、药盒上的说明看不懂、拿到病例不知道意味着什么——**直接问它，比搜索引擎更专业更科学**。
- 相当于随时有一个**免费的私人健康顾问**在旁边。

## 要点提炼

1. **按场景选工具，不求多**：工具不在多，关键每个场景有一个顺手的、用着最舒服的就够了。
2. **双工具分工工作流**：Claude Code + Opus 做需求规划 → 扣代（疑 Codex）执行，各用其长，比单用任何一个都好。**国内暂无平替**。
3. **国内平替原则**：有水平接近的就推荐（豆包、即梦、通义听悟），没有的明说没有，不强行凑数。
4. **被低估的免费工具**：通义听悟（大文件转写）、豆包输入法（语音输入）、蚂蚁阿福（健康顾问）。
5. **知识沉淀强调"不发挥"**：IMA 类 RAG 工具只针对上传内容作答，幻觉率低——这是作者选择知识库工具的关键标准。
