# 2026 年 AI 产品推荐

> **状态**：unreviewed
> **最后更新**：2026-08-07
> **来源**：[[raw/文档/2026我最常用的AI产品]]（庞贝个人使用清单，2026年5月）

## 核心要点

- 庞贝日常使用 14 大类 AI 产品，覆盖知识问答到 AI 硬件
- 每类给出海外版和国内替代方案，方便不同场景选用
- 核心工作流：Claude Code + Opus 4.7 做规划 → Codex + GPT-5.5 做开发执行
- 自研项目 AIHOT（AI 热点资讯聚合）预计 2026 年 5 月后免费开放

## 分类推荐

### 1. 知识问答
- **GPT-5.5**（海外）— 幻觉极低
- **豆包**（国内）

### 2. 内容创作与知识管理
- **Claude Opus 4.6**（海外）— 独一档，明确不推荐 Opus 4.7
- **DeepSeek V4 Pro**（国内）

### 3. 数据分析
- **Codex + GPT-5.5**（海外）
- **Claude Code + GLM-5.1**（国内）

### 4. 前端设计
- **Gemini 3.1 Pro**（海外）
- **Kimi K2.6**（国内）

### 5. 架构规划
- **Claude Code + Claude Opus 4.7**（海外）
- **Claude Code + GLM-5.1**（国内）

### 6. 代码开发执行
- **Codex + GPT-5.5**（海外）
- **Claude Code + GLM-5.1**（国内）
- 💡 **推荐工作流**：CC + Opus 4.7 做规划 → Codex + GPT-5.5 做详细开发

### 7. 深度研究
- **ChatGPT DeepResearch**（海外）
- **豆包**（国内）

### 8. 图片与平面设计
- **GPT-image-2**（海外）— 独一档
- **即梦 Seedream-5.0-lite**（国内）

### 9. 视频生成与编辑
- **Seedance 2.0**（国内）— 运动质感
- **可灵 3.0**（国内）— 电影质感，原生 4K

### 10. 音乐生成
- **Suno v5.5**（海外）
- **MiniMax Music 2.6**（国内）

### 11. 3D 生成
- **TripoAI**

### 12. AI 输入法
- **豆包输入法**（国内）— 语音输入突出

### 13. AI 硬件
- **飞书录音豆** — 语音对话 Context 导入飞书会议纪要
- **GetSeed 录音卡** — 日常记录，获取新认知

### 14. AI 热点资讯
- **AIHOT** — 庞贝自研，浓缩三年 AI 自媒体经验，预计免费开放
