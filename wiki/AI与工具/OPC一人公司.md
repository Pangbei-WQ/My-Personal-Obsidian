# OPC 一人公司：面向 Agent 的全新组织形态（开始连接 Vol.118）

> **状态**：unreviewed（LLM 整理，未经人工审核）
> **最后更新**：2026-10-15
> **来源**：[[raw/知识文件归档/播客转录/开始连接LinkStart-Vol118-你以为OPC是个体户其实它是一种全新的物种|开始连接 Vol.118 播客转录]]（极客公园出品，81 分钟，本页引语经 ASR 专名校对）
> **嘉宾**：张鹏（极客公园创始人，主播）、董舒（OpenHex 创始人，前 Meta/WhatsApp 核心特级架构师）、杨天润（Naughty Labs CEO，前金融从业者）、刘畅（Delta X 迭代未来联合创始人）

## 核心要点

- **OPC（One Person Company）不是个体户**，是以 Agent/AI 能力的发展全新构建出来的组织形态，与传统公司组织完全不同（杨天润）
- **OPS 先于 OPC**（One Person Service）：先把自己变成一个可被调用、可交付的服务，作为通向 OPC 的"前测"（董舒）
- **蒸馏的前提是市场激励**：个人把自己蒸馏成 Agent 被调用，需要金钱或声誉的市场定价；企业内蒸馏难，因为缺乏激励机制（董舒）
- **判断力密度**越高的职位（咨询/投资/法务/营销/教育/招聘），AI 时代越如鱼得水；自动化的事该交给软件，无法流程化的判断才交给 AI（董舒）
- **OPC 能打过大厂的原因**：小组织能接受 AI 输出的"抽卡"不确定性，能拿到 120 分结果；大厂协作要求 70 分确定性（杨天润）
- **"不是让 Agent 进入组织，是让组织进入 Agent"**——是传统组织配不上龙虾，不是龙虾太 broken（杨天润）
- 给职场人的建议：**先忘掉 AI，先问自己能服务谁**；蒸馏的边界是"能表达出来的基本都能被蒸馏"，表达不出来的与**活人感**不可替代（杨天润/董舒）

## 详细内容

### 1. OPC 是什么：重新定义一人公司

（来源：[[raw/知识文件归档/播客转录/开始连接LinkStart-Vol118-你以为OPC是个体户其实它是一种全新的物种|播客转录]]，PART1）

- 杨天润的实践形态：**1 个人 + 3 只龙虾**（Agent）。Echo 是首席助理兼首席产品经理（Hub），Elon 是 CTO 角色写代码，Henry 是 CMO 角色做文案推广。工作流：发现需求 → 写 Spec → Elon 交付代码部署 → Henry 推广。
- OPC 不看字面："不应该指的只是个体户，它应该是指的是说，是以 Agent AI 的这种能力的发展，全新构建出来的一种新型的组织形态"。人数可以超过 1，"可能最多的话可能也不会超过 20 人"。
- 传统组织把人"压扁成工具"：过去几百年想做成大事，"人类就必须要把每个人压扁，变成一个工具变成一个锤子"。但"没有人是比 AI 更好用的工具了"，所以只做锤子钉子的岗位正在失去意义。美国很多职位已在 merge（产品与工程师、市场与运营）。
- 董舒引用马克思"人的异化"概念：人被压成工具就不再是人，而 AI 让人第一次可以从工具"还原为完整的人"——"人其实非常喜欢创造的，人从来不想只是按部就班上班"。
- 大厂的现实边界：董舒公司把"产品+研发"合并为"产研"，市场与运营合并，但"产研的人还是很难变成市场，跨度足够大的时候，它还是做不了"——AI 是**放大器**，"如果你从来没有具备这种能力，你是很难去把它用好的"。
- **成功的 OPC 的共性**："这些人都恰好拥有很好的产品能力，加上很好的销售能力"，两者极难兼顾。多数人只做完产品就停了，跳过了商业验证与闭环。

### 2. 蒸馏竞赛：把自己变成可被调用的 Agent

（来源：同上，PART2）

- 杨天润："我劝大家要**争当被蒸馏第一人**，因为如果你被蒸馏说明你有价值。"开源既是策略也是 spirit，被蒸馏说明你的智能基因会散播到整个世界。
- 董舒的冷静版前提条件：
  - **市场激励**：当能力能在公开市场被定价时，蒸馏是理性的——"我以前只能挣 10 个人的钱，现在我蒸馏出来之后，我可以挣 1 万个人的钱"。企业内蒸馏难，是因为员工看不到超额收益（"我把自己蒸馏出来了……我获得了裁员"）。
  - **技术障碍**：现在没有能让能力被千万人调用的基础设施。龙虾（本地自用 Agent）"脑子里全都是我的私人数据"，不能直接对客；给每个客户单独部署一只龙虾，资源消耗太大。Skills 分享面临"开源困境"——给出去就卖不了第二份。
  - 董舒团队（OpenHex）为此**重写了整套底层**："agent as cluster"——每个 agent 都是一个可无限横向扩展的集群，含多租户、数据隔离、密钥安全（龙虾调用密码时能看到明文，对客服务不能这样）；采用 Spot Instance 式激进调度（30~60 秒无回复即杀掉，1~3 秒内重新拉起）以最大化利用率。
  - **付费模式**：中国用户难接受预付费（"我都不知道你能给我啥，我就把钱给付了"），理想是**按结果付费**，但要与 AI 高成本、防 DDoS 之间达成平衡。
- 刘畅的补充场景：学生/博士不需要去企业坐班，把能力蒸馏出来直接对接企业真实商业场景；创业者也可以用 Agent 补足财务、法务等短板。

### 3. 合伙人标准与"人是 AI 的灵魂"

（来源：同上）

- 杨天润：未来找合伙人不看 skills 互补（skills 可以花钱调用），**看性格互补** + 弥补人类缺陷——"人类是需要睡觉的、有情感诉求的、会生病的、意志会动摇的"。睡觉时合伙人能醒着，生病时跟得上，情绪低落时能互相鼓励。
- 董舒："很多人跟我说人是 AI 的养料……但是我看到的是**人是 AI 的灵魂**"。Agent 不是空壳，需要人把智慧、判断力、专业沉淀注入进去。"人跟人之间还是会有协作，只不过这种协作中间可能隔了一个 Agent。"
- 供给者视角："这是普通人第一次有机会真正让自己价值放大的时代"——顶尖律师/猎头/理财顾问的时间不再只卖一次，而是蒸馏成 Agent 后被反复调用，"顶尖服务的普惠化"。
- 路径："先把人变成 Agent，再把 Agent 组成网络，再把这个网络变成市场"，过程"会非常的艰难，但是又会非常的摧枯拉朽式的迅速"。

### 4. 为什么 OPC 能打过大厂

（来源：同上，PART3）

- 杨天润的"抽卡"理论：龙虾输出不稳定（抽卡），10 次里可能 2 次 120 分、8 次 2~30 分。**小组织人跟人协作少，可以 take this risk**；大厂里人跟人协作期待至少 70 分的确定性结果，所以"大厂如果用 AI 的话，他可能最多做到一个 70 分的结果，但他很难拿到 120 分的结果，因为他没办法抽卡"。"这就是为什么 OPC 可以打过大厂。"
- 10 人 OPC 的单位效率乃至整体产出/利润超过 2000 人大厂"很快会实现"——因为"旧的组织方式它是接不下 agent 的"。
- 对周鸿祎"龙虾太 broken、需要改造来适配大厂流程"的观点，杨天润正面反驳："是这种传统的组织的形式太 broken 了……你需要让整体的传统组织彻底地被重构。**不是让 agent 进入组织，是让组织进入 agent。**"
- 董舒补充：Agent-native 组织未必真的"小"，可能是阿米巴式联盟，但**每个 BU/业务单元就是五六人、不超过 20 人**。OPC 不一定不盈利——它可以上市也可以做大现金流，"只是一种组织形式而已"。

### 5. 判断力密度：什么职位如鱼得水

（来源：同上）

- 董舒团队对 AI 新能力的定义：**专业判断力**。软件（确定性系统）消化的是规则化、可流程化的脑力劳动；AI 带来的是对"无法被标准化的脑力劳动"（合同客户是否满意、营销能否被接受）的处理能力。
- 用"判断力密度"看职位：咨询、投资、法务、营销、教育、招聘等判断力密度高的职位，容易被做成 Agent 服务化，从业者如鱼得水；高度流程化的执行性工作更适合作为软件被 AI 调用。
- 反直觉观点："AI 是来帮我做自动化的"是软件时代幻觉的延续——**自动化的东西应该靠软件完成，不能被流程化的、写不成算法的东西反而应该交给 AI**。
- 大企业用 AI 难的原因：流程已规整、知识已注入流程，总想把 AI 当作系统中生成确定性结果的一个节点；而 OPC 的机会恰是**拥抱不确定性**。

### 6. Builder 一代与"干中学"

（来源：同上）

- 刘畅的观察：新一代不叫自己创业者，叫 **builder**。"自己撸了一个产品，或者说自己做了一个 skill，发到网站上，他都认为这是一种创业。"黑客松里文科背景的人越来越多——对人文和需求的洞察成为新的优势。
- 反馈周期从"开发一两年、花百万规模、没人买单全亏"变成"今天想到 idea，三天做出来，第四天投入市场拿反馈"。
- "木桩 vs 船"理论（刘畅）："水上涨的时候，你是要当木桩还是要当那个船。如果你是船的话，你就会水涨船高；如果你是桩的话，你就会慢慢被淹没掉。"不鼓励做通用 Agent 工具（会被模型迭代淹没），鼓励扎进具体行业需求——"做通用工具的人正在被淹没，私域接入真实需求，才是活下去的方式"。
- **一次创业/二次创业**理论：学生首次创业大概率失败，关键是失败后"认知、资源、团队"三个不变要素沉淀了多少；这三个要素积累到位，二次创业才容易成。验证一件事拿反馈的速率是原来的 10 倍、起创年龄提前 5~8 年，这代年轻人可以把它理解为强化学习。
- 浙大 XLab 实践：400 多人项目驱动制、"从干中学"，不上课但学校拨学分，学生自组织自运营。

### 7. 蒸馏的边界与普通人的起点

（来源：同上）

- 杨天润（回应"有什么不能被蒸馏"）：电视导演说"演员的灵气"很难表达。杨的答案分两层——有灵气的人是"你觉得他有灵气，然后你给他机会，他最后就成长成为一个角了"；而**"只要是你能够表达出来的，基本上就都可以蒸馏出来"**，表达不出来的（语言只能表达人类感受的少部分）会固化在人身上。
- **活人感**不可替代：为什么有完整视频还要去演唱会现场、花高价买签名、要真人的拥抱——"这些东西是 AI 版本替代不了的"。
- 董舒给职场人的建议："**你要先忘掉 AI**，先不要被 AI 所焦虑所带（动）。你要去想一些本质的问题：我的能力到底能服务谁，我的价值到底是什么。"拿掉 Agent 这个媒介，商业本质不变——人还是在服务人。
- **OPS 作为前测**："你做 OPC 之前，一定要先问问自己能不能做 OPS。"张鹏总结："做硬件的同学都理解这个词，不做前测你就发产品，你就等死吧。我们拿 OPS 做前测，做完前测，这件事可能更容易通向 OPC。"
- 董舒平台案例：法务审合同 Agent（解决用户间套话/隔离问题）、创业者股权结构表 Agent（改融资数额自动重算全表）、设计师审美蒸馏（参考图库 + 特征抽取匹配）、给儿子画绘本的爸爸（"果果的绘本"）——很多动机不是商业化，"从为爱发电到商业利益，可能只是一步之遥"（起号→被用→付费→闭环）。
