## 二、值不值得去？（双向钢人论证）

> 这类"要不要去一家信息不透明的公司"的判断，别只看单面。把两边都拉满，再找那个"一票否决"的变量。

- **支持去（最强理由）**：契合你的跨境采购方向；公司处在扩张期（12→28 人），**早进入 = 可能拿到更大职责**；"高级采购"title 若属实，对履历是加分；面试成本低，去一次就能把"信息真空"补上一大块。
- **反对去（最强理由）**：公司太新太小、稳定性差；title 可能"挂羊头"（实际打杂）；唯一匿名评价指向"招聘真实性/待遇"问题；信息不透明本身是种风险——**你看不清它，它也未必值得你把职业安全押上去**。
- **关键变量（真正决定结论的那一个）**：**这个"高级采购"到底是不是"真采购"**——即你有没有**实际的供应链决策权**（选品/定价/谈判/供应商管理），还是只是"下单跟单的万能岗"。次变量：**老板/直属上级是否靠谱**（决定你能不能学到东西、待不待得住）。
- **判断**：**值得去面试，但保持审慎、按"尽调"对待**。别在信息不明时投入过重（别急着辞职、别接受口头承诺）；用一次面试 + 反问清单 + 眼见为实来给这家公司"定价"。
- **下一步行动**：① 面试带本文反问清单去问；② 现场看办公环境/团队规模/在岗人数（是否与"28 人"对得上）；③ 拿到 offer 后**书面**核实合同主体、薪资结构、社保基数、试用期、双休、加班。

### 3.4 三道"岗位专属必背题"（照着 JD 出的，务必背熟）

1. **"给你一个 PM 的需求，你怎么快速找到符合要求的产品和供应商？"**

## 四、预面试回答（问题 + 怎么答）

> 通用答题心法（来自 [[采购面试-制造业三类能力题]]）：面试官问的是"业务动作"，验证的是"**你背后有没有决策框架**"。**别报动作清单，报'对齐条件 → 拆解 → 交叉验证 → 判断风险'的思考链。**

### A. 开场与动机

**A1. 请做一下自我介绍？**
- 骨架：姓名/背景一句 → 采购经历一段（2 年，跨境电商 + PMC，管过供应商开发、补货计划、降本）→ 一句收尾。
- 示范结尾："我做采购不是砍价，是**选好供应商、管好需求、跑通全流程、顺手把成本降下来**。"
- 📌 一句话调用双子案例："我做过一次**独家供应商汰换，综合费用降了 30%**，也独立**从 0 搭过跨境补货体系**，所以既懂谈判寻源，也懂用数据管库存。"

**A2. 为什么离开上一家？**
- 不说前东家坏话。示范："想往**更懂品类、能主导谈判、能管出供应商绩效**的方向走，现在的平台这件事做不完。"

**A3. 为什么选我们（豹团）？**（**高危题——你其实还没完全搞清它做什么**）
- 诚实且稳：先讲**方向契合**（电商/跨境供应链），再顺势反问一句把球踢回去。
- 示范："我理解贵司是以**互联网销售 + 供应链**为核心的方向，这正好是我的战场——我做过**跨境供应商汰换和补货计划 0→1**，能比较快上手。**不过我今天也很想确认一下，贵司现在采购这块最想解决的痛点是什么？**"
- ⚠️ 别硬编公司业务，会被追问穿帮；**用"方向契合 + 反问"既安全又显得专业**。

**A4. 你认为采购最重要的能力是什么？**
- 示范："沟通谈判是基本功；往上走，是**把不确定的需求理顺、把供应商管出绩效**，而不是天天催单砍价。"

### B. 专业能力题（调用能力框架 + 你的 STAR）

**B1. 如何判断供应商报价是否合理？**（成本与商业判断类）
- 四步框架：**对齐可比条件 → 成本拆解 → 交叉验证 → 下判断**（合理性/风险/谈判空间）。
- 一句话内核："重点不是选最低价，而是**判断这价格是否合理、风险是否可控**。"
- 📌 接你的案例："我给供应商谈判时不只是压价——是先把**核算口径**（比如物流按体积怎么算）谈清楚，再谈时效承诺和风险机制，最后综合费用降了 30%。"

**B2. 如何开发和评估一家新供应商？**（供应商开发与管理类）
- 逻辑链：**定准入门槛 → 寻源预审 → 多维评估（技术/产能/质量/交付/成本/经营风险）→ 打样试单验证 → 导入后持续管理**。
- 一句话内核："重点不是把供应商找进来，是证明他**能不能持续稳定满足要求**。"
- 📌 直接上案例 1（展会寻源引入 B、C，按区域分工，验货体积误差 38%→13.8%）。

**B3. 采购怎么帮公司降本？**（降本专项，[[采购面试-降本怎么回答]]）
- 四步：**立论"降本≠砍价，是算总成本（TCO）" → 降本四条路（物料/商务/运营/质量）→ 落地动作+数据（成本分析表）→ 量化结果（降本额/降本率）**。
- 📌 量化弹药："上一段我**主导整车干线换成固定合约价，周均省 1400 元**；跨境物流供应商汰换**综合费用 −30%**；这就是'降本额'这把硬尺子。"
- ⚠️ **千万别张口就说"砍价压价"**——这是 10 个里被淘汰 9 个的答案。

**B4. 供应商突然断供 / 严重延期怎么办？**（供应风险与异常处置类）
- 四步：**盘库存与在途 → 梳理受影响订单、确认最晚到料与停线风险 → 核实供应商（已完成量/恢复时间/分批交付）→ 启动备选/替代/安全库存/加急物流 + 跨部门同一份行动清单**。
- 红线：**替代料必须完成技术与质量确认才能切换**。
- 📌 接案例 1："我原东家就是**独家供应商**，服务劣化（延误、两次被查验退运），我就是靠'**引入二供 + 区域分工**'把这个单点风险拆掉的。"

### C. 情景题（[[采购面试-三类情景题]]，节奏：先判断 → 再应对 → 收口）

**C1. 价格情景：供应商说"这价格我做不了"，怎么办？**
- 三步：**要报价结构、成本拆解验真伪 → 拿筹码（账期/锁量/增量）交换 → 历史数据对账**。
- 内核："**价格是拆出来、换出来、算出来的，不是压出来的。**"
- 📌 接案例 2："我谈整车物流时，就是用'**固定合约 + 稳定货源**'换到了比现货散车更低的价格和更好的履约。"

**C2. 垄断情景：独家供应商坐地起价，怎么办？**
- 考点在**事前布局**：双源/多元储备 → 合同锁价（触发条件/涨幅上限）→ 涨价时拿"替代方案+长期量+账期"重谈。
- 内核："**独家不是不能有，是不能没有任何对冲的方法。**"
- 📌 你有现成故事——案例 1 就是打破独家。"**第二家哪怕量最小我也养着**，不然出事就被人拿捏。"

**C3. 交付情景：交期一拖再拖、产线/活动快停了，怎么办？**
- 四步：**定位根因 → 盘库存在途+最晚到料+停线风险 → 启备选/替代/安全库存/加急 → 跨部门同一份风险清单**。
- 内核："**拼的是定位根因的速度和预案的厚度**，不是天天催。"
- 📌 可引案例 3（补货体系里前置"到货前缺货 SKU 清单 + 缺货时间"，把救火变预警）。

### D. 行为 / STAR 题

**D1. 最得意的一件事？**（用 STAR，讲"靠供应商管理或流程改进解决长期问题"）
- 📌 首选案例 1（供应商汰换，成本+服务双赢）；或案例 3（补货体系 0→1，把"拍脑袋订货"升级为"数据化订货"）。

**D2. 最失败/最挫折的一件事？**
- 讲**真实教训 + 你改了什么**，**不甩锅**。骨架：承认 → 根因（我的判断/方法问题）→ 改进动作 → 后来的结果。
- 参考：早期"容易把供应商当对手、姿态偏硬"，后来发现**长期关系比单次低价更值钱**。

**D3. 你的缺点？**
- 真实、不致命、已在改进。同上"猎人 → 牧人"的转变即可。

### E. 合规与操守（送分题，答干净加分）

**E1. 供应商请吃饭/送礼怎么办？**
- "公司有规定按规定；没规定也主动报备。正常商务饭局 AA 或公开化，超尺度回绝。**供应商敬的不是我，是我背后的采购额；我越干净，谈判腰杆越硬。**"

**E2. 领导/熟人塞供应商怎么办？**
- "流程面前人人平等——走正常打样、验厂、比价、试产，**用数据说话**。不硬顶领导，也不坏规矩。"

## 五、你要反问的问题（定制版 · JD 更新后）

> 反问 = 你的"尽调工具"。**边问边观察对方答得清不清楚、闪不闪躲。** 业务已确认是跨境 B2C，反问重点转到**平台 / 品类 / 开发 vs 执行比例 / 待遇**。

**A. 关于平台与品类（决定你能不能复用经验）—— 新增重点**
1. 公司**主要做哪个平台**？Amazon 为主，还是独立站 / Walmart / TikTok 都有？
2. 模式是**精品、精铺还是铺货**？**主要品类**是什么？
3. 我要负责**哪个品类**？和我的背景（纺织 / 玩具 / 塑料产业带、跨境物流）搭不搭？

**B. 关于岗位真实性（最关键的验证）**
4. 这个岗位是**新增还是补缺**？如果是补缺，**前任为什么走**？
5. 采购是**"选品开发型"（帮 PM 找新品/新供应商）**为主，还是**执行跟单**为主？**开发 : 执行**大概几比几？有没有**定价 / 供应商选择**的决策权？
6. 采购团队**几个人**？我**汇报给谁**？和 PM / 运营怎么配合？
7. **考核指标**是什么——新品开发数？降本额？按时交付率？还是"领导说了算"？

**C. 关于业务现状（补上信息真空）**
8. 现在**有多少家活跃供应商**？集中在哪些区域？
9. **交货达成率**目前大概多少？异常多不多？（判断这岗位是"救火"还是"建制"）
10. 有没有 **ERP / 供应商管理系统 / 选品工具**，还是纯 Excel + 1688 手工找？公司从去年 12 人扩到 28 人，**接下来一年规划**是什么？

**D. 关于工作条件（白纸黑字前置）**
11. **双休还是大小周 / 单休**？旺季 / 大促前加班、出差频率？
12. **社保公积金**按什么基数缴？**试用期**多久、薪资结构（底薪 / 绩效占比）怎么算？

> 💡 收尾话术（体面且显专业）："我很看好贵司做跨境的方向，也想确认一下双方是不是真的匹配——所以问题问得细了点，抱歉。"

## 六、面试当天备忘

- **带**：打印简历（供应商开发版为主）、[[履历与项目案例库]]里三个核心案例的数字（−30% / 38%→13.8% / 1400 元 / 243 SKU）背熟。
- **着装**：商务休闲即可（小公司电商氛围，不必过度正式）。
- **眼见为实**：到场看**办公区人数、在岗氛围、是不是真在做业务**；记下"实际在岗人数"回来和"28 人"对一下。
- **红线**：任何"先交钱/培训贷/押金/扣证件/刷单/拉人头"信号，**立刻撤**。
- **心态**：这是**双向尽调**——你在评估它，不是单方面求它。带着本文第五节去，问不倒你。
