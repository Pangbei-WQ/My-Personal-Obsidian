## 核心要点

- **一句话画像**：2 年供应链采购/计划经验，**"既懂业务、又会建模"**——既能自主抓 ERP 数据搭模型，又能把库存转成金额和结构推动运营落地。
- **三条可复用的王牌战绩**：跨境物流供应商汰换（**费用 −30%**、验货体积误差 **38% → 13.8%**）、国内整车干线降本（**周均省 1400 元**）、跨境补货计划体系 **0 → 1**（243 SKU / 约 150 万库存金额）。
- **两个求职方向**（同一履历的两种叙事）：
  - **供应商开发** → 强调寻源、汰换、谈判、降本闭环。
  - **供应链计划 / 交付计划** → 强调再订货点建模、库存健康度、交付履约。
- **理论背书**：履历中"再订货点 / 安全库存 / 加权日销"等做法与 [[wiki/供应链管理/读书笔记/《采购与供应链管理》第4版|刘宝红]] 方法论互为印证。

## 二、STAR 案例库

### 案例 1｜跨境物流供应商结构优化与汰换 ⭐ 最强案例

- **S（背景）**：原**独家**供应商 A 服务劣化——综合费用偏高、**验货体积误差达 38%**、物流延误概率高，特殊时期两次被查验致退运重发，交付与成本双失控。
- **T（任务）**：打破独家依赖，重建供应商结构，同时降本 + 提服务。
- **A（动作）**：
  1. 通过**行业展会主动寻源**，引入 B、C 两家新供应商；
  2. 按**区域分工**：B 承接美国/加拿大线，C 承接英国/欧洲线；
  3. 主导价格、**体积核算标准**、时效承诺、**风险告知机制**的谈判。
- **R（成果）**：综合物流费用较 A **下降 30%**；验货体积误差 **降至 13.8%**；服务升级——B 发货前预警途经国家形势与延误风险，C 新增铁路运输方式。
- **可迁移的方法论**：独家供应商风险 → 主动寻源引入竞争 → 用"核算口径 + 风险机制"而非单纯压价来谈判 → 结果同时覆盖成本与体验。

### 案例 2｜国内整车物流供应商开发与降本

- **S**：学生季「揭阳—福州」整车干线，运满满散车价高（9.6 米含税 2500 元/趟、17.5 米含税 3700 元/趟），司机沟通难、装货异常需临时加价。
- **A**：主动寻源并谈判，签约一家物流公司**固定合约价**。
- **R**：签约价 9.6 米 2300 元/趟、17.5 米 3300 元/趟；发票及时、装货问题专人对接、基本无额外加价；窗口期每周 2 车 17.5 米 + 3 车 9.6 米，**周均节省运费 1400 元**。
- **可迁移的方法论**：现货散车 → 固定合约，用**履约确定性**（发票、对接人、无临时加价）换取价格，而不只是比单价。

### 案例 3｜跨境补货计划体系 0 → 1 ⭐ 计划方向核心案例

- **范围**：跨境业务（印尼等两市场，**243 个通用 SKU、约 150 万库存金额**）。
- **做法**：
  1. 独立搭建补货计划工具，**自主抓取 ERP** 实时库存、周销量、到货批次与排柜到柜历史；
  2. 结合运营加推/下架/上新动作生成**产品计划下单表**；
  3. 梳理 **SKU 分级管理**逻辑（按优先级区分订货/催货/暂不处理）；
  4. 采用**再订货点法**，综合订货频率、安全库存、提前期、缺货时间、节假日等因子测算补货量——把"提前期 × 日销 + 拍脑袋"升级为"**加权日销 + 运营判断**"的数据化订货；
  5. 按**整柜体积**规划 SKU 组合与厂家顺路装柜顺序，取代"装不满就散货"模式，节省货代派柜时间；
  6. 解决印尼「单装 SKU」与另一事业部「10 装 SKU」的**编码转写难点**。
- **成果**：降低缺货风险、提升库存与厂家订单稳定性。
- **可迁移的方法论**：数据化订货替代经验订货；整柜思维替代散货思维。

### 案例 4｜跨境库存健康度分析体系

- **S**：原先只有"总库存、总销售"两个数的**粗放状态**。
- **A**：搭建库存分析体系，把原始数据转化为库存金额、数量与**库存健康度结构**（含库存周转天数、成本占比、销量波动幅度，区分缺货/滞销/推销售）；每月输出库存健康度分析；建立「**分析 → 建议 → 限期执行 → 原因回溯**」跟进机制。
- **R**：推动运营落地清库、推销售动作。
- **可迁移的方法论**：把"库存数字"变成"结构 + 动作"，并配一个闭环跟进机制，否则分析无人执行。

### 案例 5｜英氏京东自营每周出货表

- **做法**：抓取实时库存、周销量与历史销量存档；计算各 SKU **波动系数**并据此做历史销量取值；按**加权日销**测算不同销售等级 SKU 的补货量；同步输出**到货前缺货 SKU 清单与缺货时间**，支持提前预售处理。
- **可迁移的方法论**：波动系数 → 历史取值 → 分级补货，并把"缺货预警"前置到下单环节。

### 案例 6｜其他职责与早期经历

- **供应商协同**：配合财务梳理**供应商开票优先级规则**（货款规模 + 合作等级），优化采购与供应商对接协同。
- **产业带认知**：熟悉纺织、玩具、塑料等货品特性与产业带分布（安徽纺织、潮汕汕头玩具、揭阳塑料制品及原料加工），据此匹配最优物流方案 / 支撑供应商评估开发。
- **盛辉物流（管培生实习）**：参与福州仓储部北京窗口仓配流程梳理（「开单 – 配载 – 出库」节点衔接）与星网锐捷仓库搬迁项目，优化货物分类存放与动线规划。
- **夏天移动营业厅（代理店长）**：参与高校校园网营销方案设计与营业厅「基础通信 + 衍生业务」组合规划，方案在部分高校复用。
- **青蛙王子（仓库助理）**：参与仓库物料分类存放与台账管理梳理，协助建立库存动态监控与补货提醒的数据逻辑。
