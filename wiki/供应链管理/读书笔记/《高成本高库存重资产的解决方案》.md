# 《高成本、高库存、重资产的解决方案》第2版

> **状态**：unreviewed
> **最后更新**：2026-08-07
> **来源**：[[raw/知识文件归档/供应链管理-刘宝红/4、《供应链管理：高成本、高库存、重资产的解决方案 第2版》2023年]]
> **作者**：刘宝红 | 2023年第2版 | 机械工业出版社

## 核心定位

> 📌 "生意越做越多，钱越赚越少；账面上赚了，都赚到库存和产能里去了。"

这是六本书中的**总纲**——提纲挈领地为供应链绩效改进提供整体框架。另外几本书是对框架中具体模块的展开。第2版是作者花了9个多月、写了5稿、从20万字精简到16万字的重新创作。

---

## 核心框架：前端防杂、后端减重、中间治乱

```
        前端防杂                中间治乱                后端减重
    ┌──────────────┐    ┌──────────────┐    ┌──────────────┐
    │ 降低复杂度     │    │ 改善计划      │    │ 走轻资产之路   │
    │ 提高规模效益   │ →  │ 控制库存      │ →  │ 提高供应商能力 │
    │              │    │ 平衡需求与供应 │    │              │
    └──────────────┘    └──────────────┘    └──────────────┘
         产品管理              需求管理              供应管理
```

三者相互纠缠、恶性循环：
- 产品线越长 → 批量越小 → 计划越难做 → 库存越高 → 产能利用率越低
- 产能利用率低 → 建更多产线 → 重资产更严重
- 重资产下 → 产能不能闲置 → 接各种边角料订单 → 进一步增加产品复杂度

## 第一篇：前端防杂——降低复杂度

### 核心论点

> 📌 "价格由市场决定，成本由复杂度决定。"

复杂度是成本的驱动器。复杂度降低 → 组织流程简化 → 复杂度驱动的成本自然降低。

### 复杂度从哪来

1. **粗放经营**："多子多福"分散风险 → 导入过多产品线和型号
2. **没有约束的创新**：误把"不同"当"差异化"
3. **市场饱和下盲目维持增长**：进入各种边角料市场
4. **复杂度由专家出于善意搞出**（不是客户要的）
5. **能力短板**：从螺丝钉的复杂度可见一斑

### 应对措施

- **从产品开发上升到产品管理**：有人对产品的全生命周期负责
- **销售从接订单上升到管需求**：不是客户要什么都接
- **供应链早期参与需求定义**：在设计阶段就把复杂度控制住
- **精简老产品**：分得清的就留下，分不清的清理
- **复杂度控制三级跳**：产品标准化→模块化→系列化

> 📌 "复杂度控制是个持久战。"

## 第二篇：中间治乱——改善计划

### 核心论点

> 📌 "整体而言，库存是个计划问题。"

### 计划薄弱的深层原因

1. **职业经理人问题**：没计划意味着有多个计划（销售有计划、采购有计划、生产有计划，各做各的）
2. **借口文化**：没计划助长了"做不到是因为没计划/计划不准"的互相推诿
3. **劣质客户循环**：没有计划性 → 紧急插单 → 让供应商觉得我们是劣质客户
4. **兼职计划**：公司大了，计划不能再是兼职职能
5. **计划是最后一站**：最优秀的人不去计划部门

### 改善路径

- 从需求预测开始的"计划链"贯穿整个供应链
- 销售预测 ≠ 需求预测 ≠ 销售目标
- **需求预测**：从数据开始，由判断结束
- 推动信息化，用信息换库存
- 设定绩效考核，保护计划"抬头看路"

## 第三篇：后端减重——走轻资产之路

### 核心论点

> 📌 "能力越低，资产就越重。重资产是供应链管理和整合能力不足的替代品。"

### 垂直整合的重资产三大问题

1. **规模效益低下**：自建工厂只服务自己，需求单一
2. **内置资源劣质化**：没有竞争压力，能力退化
3. **成本缺乏竞争力**：同样的资源，专业供应商成本更低

### 从重到轻的路径

1. **聚焦核心竞争力**：三个条件——①能带来显著竞争优势 ②优于竞争对手 ③难以模仿
2. **外包非核心业务**：但要先有能力选好、管好供应商
3. **选好管好供应商，避免三大误区**：
   - 误区一：分权过细，供应商成了"公共草地"
   - 误区二：轻选择、重淘汰，不作为的逃避主义
   - 误区三：过度依赖市场竞争来管理供应商

> 📌 案例：比亚迪垂直整合模式的得与失；三一重工的扩张与收缩。
