## 代表性嘉宾与核心观点

### 1. 课代表立正（康奈尔经济学博士，Superlinear.Academy 创始人，前 Amazon/Meta/腾讯，Statsig 被 OpenAI 收购）
**主题：高手怎么用 AI / 普通人怎么学 AI / 投资人如何投 AI**
- 高手时刻在想"**我能为 AI 做什么**"，把工作流、偏好都交给 AI
- **"立刻停止使用 ChatGPT"**——改用 Claude Code / Codex / Cursor / Manus 等 agentic 工具：聊天框产出无留存、无复利
- 工具与模型趋同后，差距只剩 **skill**（隐性知识显性化）与 **context**（偏好/历史/标准）
- "摸着石头过河，石头不见了"——旧创业逻辑失灵；AI 逼人做创造，未来教育是"略懂一二"一百个专业

### 2. 戴冠兰（Runta 创始人/CEO，Agent Infra，a16z 领投 2000 万美元，Jeff Dean/李飞飞天使参投）
**主题：Agent 的底座要重建**
- "**模型能力已经够了，要卷就卷 infra**"
- LLM 让执行单元变概率性，重试/幂等/事务/恢复等确定性基建被抽掉地基，须从第一性原理重建 Agent 专属底座
- 预言"**未来 10 个月必发生灾难性 Agent 事故**"；权限要动态分配、干完即收
- 安全走"管控"路线：沙盒内完全可审计、可恢复，而非扫描匹配

### 3. 何嘉斌（Ropet AI 萌宠机器人创始人，CES 2025 黑马，前微软/百度/Pico）
**主题：AI 硬件/情感陪伴**
- 要做"创造爱和爱的瞬间"的公司；AI 萌宠比人形机器人更易进消费级
- "**无声的陪伴是最难做的**""示弱很重要，我们都想照顾弱者"
- 北极星指标是开机率与互动率；"投资人不是全世界呀"

### 4. Paperboy（CEO John Yang，21 岁，团队 12 人，融资 470 万美金）
**主题：Agent 的下一种形态**
- 现有 Claude Code / Codex / Manus 都是 session-based + prompt-based：每次重来、被动等待
- Agent 应通过**观察用户电脑使用来自主学习**，用 IM（即时通讯式）而非 session，主动找你
- "**1 秒内任务用 autocomplete，几小时任务用 IM，更长周期仍是待探索区**"
- "人类和 AI Agent 的最佳配合方式，还没被发明"

## 实操建议

- **普通人学 AI**：放弃聊天框式提问，改用 agent 工具让 AI 嵌入工作流；沉淀个人 skill 与 context（把隐性知识显性化、标准化成可复用脚手架）
- **给 Agent 权限**：动态分配、用完即收、定硬规则（只能读不能发、机密目录不可访问）
- **投资人看项目**：机会两极化——"往天上跳"（AI for Science / Physical AI）与"往地里钻"（行业深水区流程改造 / FDE 前端部署工程师）
- **创业者**：Vibe Coding 可覆盖 95% 开发但工程师仍不可替代；带头降薪换股权筛选团队（Ropet 做法）；Agent 产品做连续记忆 + 主动性 + 从环境学习（Paperboy 做法）
