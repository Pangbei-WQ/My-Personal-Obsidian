# 项目工作规则

> **状态**：unreviewed
> **最后更新**：2026-08-07
> **来源**：[[raw/知识文件归档/全局工作规则]]

## 核心要点

- 这是庞贝的个人工作规则集，涵盖沟通方式、项目启动、技能使用、Git 规范
- 核心原则：**用户体验优先于技术偏好、代码整洁度和架构优雅度**
- 面向非程序员背景，强调"数据来源"和"判断依据"
- 安全第一：密钥、token、密码不进代码

## 规则结构

### 0. 最高优先级
- 用户体验 > 技术偏好、代码整洁度、架构优雅度
- 安全与不可逆操作 > 执行效率
- 不要注释掉报错来让代码跑起来，必须找根本原因
- 密钥、token、密码不进代码和仓库

### 1. 默认沟通方式
- 默认中文回复
- 代码、命令、变量名用英文
- 结论先行，再给理由
- 面向非程序员解释：说明数据来源 + 判断依据
- 模糊需求 → 先给默认方案，再说可调整点

### 2. 项目启动守门规则
- 修改文件前必须确认工作目录和项目规则文件
- 无 CLAUDE.md → 只能先创建草案，不能直接改业务代码

### 3. Skills 使用规则
- 每个任务前判断是否有匹配 Skill
- 有 → 说明用哪个及原因，再执行
- 无 → 说明"无匹配"，直接完成任务

### 4. Git 与部署
- commit message 用英文
- 不自动 push
- 改完主动跑 test/lint/build/verify
