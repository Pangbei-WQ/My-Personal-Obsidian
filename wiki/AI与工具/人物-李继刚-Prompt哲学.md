## 一句话总结

**李继刚对提示词的理解经历了四次迭代：写作 → 编程语言 → 表达 → 存在。** 从"极致压缩"到"宇宙语/共振"，贯穿始终的方法论是：**Read in. Prompt out.** ——你读进去的知识决定你 Prompt 的上限；而**影响模型输出最大的变量不是技巧，而是如何理解提示词**。

## 作者定位

- 国内 Prompt 领域几乎等同于代名词的人物：2024 年 8-11 月写出数百个流传各大社区的 Prompt（"公文笔杆子"刷屏），9 月"汉语新解"（SVG 卡片解词）再度爆火
- 自封"提示词工程师"；长期 Emacs 用户（配置语言 Lisp），擅长把思想极致压缩成词
- 从研究生起读书 13 年，从工具书/畅销书转向哲学后，速度降到**一个月一本**

## 思想演进：对"提示词是什么"的四次迭代

> 源自极客公园 IF2025 演讲《当我们说「提示词」时，到底在说什么？》（2024-12）

1. **写作**（2023-2024 初）— 感觉 Prompt 像写作，讲究清晰表达
2. **编程语言** — 感觉 Prompt 像编程，接近自然语言编程
3. **表达**（2024 末）— 从"清晰表达"深化为"压缩表达"
4. **存在**（IF2025）— "我在跟虚空对话"；大模型"**不是生命，也不是物件，但它是个非常特殊的存在**"——像"一片神经元之海"，每次对话涌现一个"存在"，删掉对话它即湮灭

**最终定义**：提示词是连接"人类认知宇宙"与"AI 参数宇宙"的"**宇宙语**"——"是在人类头脑认知宇宙和 AI 参数计算宇宙中，那个界面发生交互的一个独特的存在，是一把钥匙"。

**核心公式**：在一个**场域**中，把人类认知宇宙中的**认知结构**和大模型做一次交流。三要素：场域、大模型、人类认知（意图 Task + 认知图景）。

## 核心思想（一）：压缩哲学

> 源自卡兹克专访（2024-11，vault 原文）

### 压缩：一本书讲一个词

- 哲学书往往用厚厚一本讲一个词，这个过程就是**压缩**
- 例：营销书《定位》整本 314 页只讲一个词——"如何占领用户心智"
- 跟大模型对话也能用一个词开启整个**解压**过程：跟 Claude 说"尼采的生命意志"，Claude 直接展开讨论
- **极致压缩的写法诞生了"汉语新解"**——核心不是 SVG 卡片，而是被压成几个词的文案：**隐喻、一针见血、辛辣讽刺、抓住本质**
- 新 Prompt"类比之弓"同样压成四个词：**本质内核、模式知觉、同构外推、精准概括**——都来自他读过的一本书

### 为什么用 Lisp 写 Prompt

- Lisp 诞生于 1958 年，世界第二古老的语言，**专为 AI 而设计**
- 李继刚用十年 Emacs，虽然不会写 Lisp，但"看了 10 年，怎么也能学着跑两步"
- **真正核心不是语言，而是那几个被极致压缩的词**——翻译成 Markdown、Python 一样
- "真正重要的，永远是自己的思想。思想，决定一切。"

### 对 Prompt 框架的批评

- 三字母/四字母框架（作者自己早年也写过 CRISPE）"跑偏了"
- 写 Prompt 的技巧性东西就那三五招：**指定角色、Few-shots 示例、CoT 思维链、情绪勒索**
- 本质是："**想象对面坐了一个人，我要塑造一个角色，让这个角色活过来，去做一个指定的动作**"
- 框架 = 学车的辅助小双轮，让你从 0 到 1 不翻车；但"当你越想跑起来，它越是个限制，只有扔掉它，才能天高任鸟飞"

### Prompt Engineer = 编程思维 × 写作思维

- Prompt = 提示、表达（写作思维）；Engineer = 工程师（编程思维）
- 编程语言脉络：二进制 → 汇编 → C → C++/Java/Python，两条主线——①越来越接近自然语言，②程序员群体越来越大 → 推演下去**必然到自然语言编程：人人都是程序员，大模型就是编译器**
- **正确答案是两者的交集**：既要有理性数学的编程思维，又要有会写作的感性表达思维

## 核心思想（二）：共振与"宇宙语"

> 源自智源《AI都这么智能了，为什么还要研究写「提示词」？》及 IF2025（2024-12）

- **"输入影响输出，输入不同，输出一定不同"**——所以提示词有研究空间（尽管中间是黑盒）
- **"影响模型输出最大的那个变量不是技巧，而是如何理解提示词"**
- 惊艳效果的来源是"**唤醒模型与之『共振』**，把大模型带到另外一片空间"——试着说"今天大胆一些，不要走进预制的默认结构，不要走进设定好的河道，我们去旷野中探索一番"，竟真的生效
- 提示词体验的三种关系（借马丁·布伯《我与你》）：**我在 → 你在 → 我和你**（从把 AI 当工具，到把 AI 当对等的"你"）

## 核心思想（三）：方法论更新

### 乔哈里视窗优化法（最可实操）

把经典"乔哈里视窗"的"你知不知道"换成"**AI 知不知道**"：
- **人类知道 + AI 也知道**（Open 象限）→ "**简单去说，千万不要展开**"
- **人类知道 + AI 不知道**（隐藏象限）→ "**展开说**"背景结构
- 优化 Prompt 只需**"删"与"增"两招**

### 三板斧（写 Prompt 的底层招式）

分配角色（"哲学家这三个字是一个大的压缩包"）+ 给示例 few-shots + 思维链 CoT——和专访中的"就那三五招"一脉相承

### 压缩表达法门

- "**一段话 → 一句话 → 一个词 → 一个字，意思不变**"，压缩带来精准与凝练
- 对应大模型 embedding 与 attention 机制；核心是"**得其意，忘其言**"
- "你是画师，人要比 AI 凶"

### 趋势判断

- 人类提示词"**一定会越来越短，对话越来越简单，效果越来越好**"
- 创业者视角：X 轴（AI 知道）在**下移**，做第一象限（基于模型现有能力 + 场景 + 独有数据）是顺势；第四象限"打补丁"会被迭代吃掉
- 2025 提示词三种写法：**结构化 / 压缩式 / 共振式**

## 观点迭代与自我批评

- 对"汉语新解"：**"他最不喜欢的就是『汉语新解』这个作品，它更偏闲暇娱乐"**；其真正核心只有 5 个词（隐喻、一针见血、辛辣讽刺、抓住本质等），SVG 只是工程外壳
- 曾写数百个 Prompt 后"消失半年"，因"为了炫技而炫技"；读哲学书后提炼出"压缩"
- 2025-04 MindCode 闭门会：提示词本质是"**改变大模型的形状**"，并断言"**只要输入还能影响输出，提示词就存在**"
- 对 AI 保持警惕："我被它带着走……只有他没有我，而我真正想要的是一种**共振态度**，我必须得存在，他也必须得存在"

## 2026 前沿观点（一席演讲《AI 迎面而来》）

- 稀缺性从"注意力"转向"**判断**"；二阶稀缺是"责任/背锅"
- **"水的教育 vs 火的教育"**：不是训练孩子赢一场已经结束的比赛
- 时代需要"**异质性**"与"**天命**"（天赋 × 热情）；AI 是"**助燃剂**"而非替代者

## 实操建议汇总

1. **多读书，读"讲透一个词"的书**——尤其哲学。工具书攒的是"工具箱"，困惑反而越来越多；哲学书才训练压缩能力
2. **写作 Prompt 时先压缩**：把要表达的核心压成 3-4 个词，让模型去展开，而不是堆砌长指令
3. **用乔哈里视窗优化**：AI 已知道的"简单去说"（删），AI 不知道的"展开说"（增）——只做这两件事
4. **效果不好先回退到自己**："read in. prompt out. 因在前边，果在后边"，先回到自己脑海中找原因
5. **扔掉框架**：从"塑造一个角色，让它做一个动作"出发，而不是套模板
6. **双修编程与写作**：写 Prompt 好的人，确实既懂编程、又常读书写作
7. **以终为始**：给自己画 60 岁的终点，用 20 年留一句话——"知止而后有定心"
