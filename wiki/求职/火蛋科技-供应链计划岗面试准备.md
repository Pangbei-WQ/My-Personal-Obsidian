# 火蛋科技-供应链计划岗面试准备

> **状态**：unreviewed
> **最后更新**：2026-10-17
> **来源**：用户提供的 JD 截图、网络背调、[[wiki/求职/履历与项目案例库|履历与项目案例库]]

## 核心要点

- **岗位定位**：跨境电商（亚马逊精品路线）的**供应链计划岗**——采购计划 + 发货节奏 + 库存管理 + 平台合规 + 专项项目，与用户「交付计划」叙事线（案例 3/4/5）高度匹配。
- **总基调**：不答成「跟单员」，答成「**用数据建模驱动补货与库存决策的计划型供应链人**」。
- **两个真缺口**：① 平台合规（JD 职责 3，简历无直接对应）；② 数据工具点名度（JD 要 Power Query/BI/SQL，用户实际熟练 Excel 高级函数，PQ/BI/SQL 不会——只能诚实 + 展示学习迁移）。
- **公司关键情报**：火蛋科技**深耕亚马逊**（美国/日本/欧洲站 + 日本乐天），小家电/家居/车载/日化收纳品类——**亚马逊 FBA 补货机制与大促节奏是待补知识的第一优先级**。

## 四、预测高频题（11 题，每题标注对应画像条目）

### Q1 自我介绍（通用 · 收口画像 1/2/4）
一句背景（物流管理本科 + 2 年跨境采购计划）→ 主案例一段（0→1 搭补货计划与库存分析体系，243 SKU/150 万库存）→ 人设收尾：「我是那种既能抓 ERP 数据搭模型、又能把库存变成金额和结构推动运营落地的计划型供应链人。」

### Q2 「讲讲你是怎么做补货/采购计划的？」（画像 ①⑥）
STAR 用案例 3：**S** 印尼等两市场、243 SKU、150 万库存，原先是经验式订货；**A** 自主抓 ERP（实时库存/周销量/到货批次/排柜历史）→ 结合运营加推/下架/上新生成计划下单表 → 再订货点法综合订货频率、安全库存、提前期、节假日因子 → SKU 分级（订货/催货/暂不处理）；**R** 降低缺货风险、提升库存与厂家订单稳定性。
**追问预案**：「安全库存怎么定？」→ 服务水平 × 需求与提前期波动；「加权日销怎么加权？」→ 近期销量权重高于远期，反映趋势而非均值。

### Q3 「断货和滞销怎么平衡？」（画像 ②）
先说判断标准（这是经营问题不是数学题）：断货损失 = 销售中断 + listing 权重下滑；滞销损失 = 资金占用 + 仓储费 + 降价清货。
再给机制：① 缺货侧——再订货点 + 安全库存 + 缺货预警前置到下单环节（英氏案例 5 的缺货 SKU 清单）；② 滞销侧——库存健康度结构化识别（周转天数/成本占比/波动幅度，区分缺货/滞销/推销售）→ 每月输出建议 → 限期执行 → 原因回溯。
**收口**：「平衡的本质是把两个风险都变成可量化的监控指标，而不是凭感觉。」

### Q4 「大促前怎么备货？」（画像 ①）⭐ 亚马逊岗必考
脉冲需求应对（三道防线框架）：① 预测侧——与运营对齐促销资源（报了多少活动、预期流量倍数），按活动档位分级备货；② 库存侧——大促不靠临时补货，靠**提前期倒推下单**（海运头程 30-45 天 + 工厂生产周期 + 入仓上架时间，黑五的货 9 月就要下厂）；③ 执行侧——预留空派/快递补货通道应对超卖，事后复盘预测偏差。
**桥接**：「我现在的跨境业务也做加推场景——运营的加推/下架/上新动作是我补货模型的输入项，逻辑相通。」

### Q5 「库存分析你具体看哪些指标？」（画像 ②④）
周转天数、库存成本占比、销量波动系数、缺货 SKU 数与预计缺货时间、滞销/推销售占比；关键不是罗列指标，而是「**每个指标对应一个动作**」——周转高 → 清库/促销建议；波动大 → 调安全库存；缺货预警 → 加急催货。

### Q6 「Excel 具体怎么用？会 Power Query / SQL 吗？」（画像 ④）⚠️ 诚实应对
**会说的（真实）**：VLOOKUP/XLOOKUP 做 SKU 维度跨表匹配（库存表 × 销量表 × 在途表）；SUMIFS 做多条件汇总（按市场/品类/月份）；数据透视表做库存结构与周转分析；每天定时从 ERP 抓数后用函数链自动生成补货测算表。
**不会说的（不编造）**：「Power Query 和 SQL 我目前还没在业务里用过，现在的取数 ERP 导出 + Excel 已经跑通了完整链路；不过我的模型逻辑是通的，工具迁移成本不高，我正在学 Power Query。」（**绝不说会**；若面试官追问 SQL 概念，答「了解 select/join 的作用，未实际写过」）

### Q7 「运营不配合清货/补货建议怎么办？」（画像 ⑤）
案例 4 的机制回答：① 先用数据把建议变成「金额和风险」而非「库存数字」（滞销 30 万压着 3 个月仓储费）；② 建立跟进机制——分析 → 建议 → **限期执行** → **原因回溯**；③ 不执行的理由回溯分类：判断分歧（摆数据对齐）、资源问题（协调支持）、习惯问题（上报机制解决）。
**价值观收口**：「计划岗没有命令权，影响力来自『我的判断被验证过是对的』。」

### Q8 「你怎么理解平台合规？做过什么？」（画像 ③）⚠️ 缺口题
**框架先行**（展示认知结构）：平台合规 = 产品合规（认证：美 FCC/UL、日 PSE、欧 CE、EPR 包装法/环保注册、VAT 税务）+ 运营合规（FBA 入库要求、危险品审核、类目限制、知识产权/专利——火蛋 60+ 专利说明他们很在意）+ 供应链合规（物流渠道资质、带电产品运输要求）。
**诚实桥接**：「我之前做印尼市场，需要自主解读当地平台的清关、认证与类目政策并调整发货方案；亚马逊的规则体系更复杂，我的方法是一样的——政策发布后第一时间解读，转成采购和发货环节的检查清单。」**面试前务必把第六节的知识清单过一遍**，把「方法正确」变成「内容也说得出」。

### Q9 「发货节奏怎么定？头程物流怎么选？」（画像 ①）
素材：案例 3 的整柜规划 + 案例 1 的货代管理。
① 节奏：按再订货点触发 + 整柜体积规划 SKU 组合（拼柜装载率），取代「装不满就散货」；② 头程选择：海运为主控成本（慢但便宜，适合计划内补货）、空派/快递做应急（贵但快，适合断货救火），选择依据 = **断货风险 × 时间窗 × 货值**；③ 供应商管理：核算口径统一（体积误差 38%→13.8% 的教训）+ 风险预警机制。

### Q10 「为什么离开现在的公司？为什么选火蛋？」（通用）
不贬前东家：「我在现在的公司完成了从 0 到 1 搭计划体系，学到了完整的方法论；但业务体量和品类深度有限，我想去**精品化、多站点**的平台，把这套方法在更大的盘子上验证。」选火蛋：「贵司聚焦长周期冠军品类 + 品牌化路线，这对库存计划的精度要求最高，正是我擅长且想深耕的方向。」

### Q11 「说一件最失败/最有教训的事」（通用）⚠️ 案例库缺失败版
**待用户挖掘**——候选方向（基于真实素材，需用户确认细节）：验货体积误差 38% 事件（独家供应商风险的代价 → 学会主动寻源建立竞争）是现成的「教训 → 改进」结构，可按真实经过组织。**绝不编造**。

### 情景题补充包：采购/供应商场景 × 4（对接知识库题库）

> 📝 **来源与筛选（专家判断）**：题目框架取自 [[采购面试-三类情景题]] 与 [[采购面试-制造业三类能力题]]（"先判断 → 再应对 → 收口"节奏），语境改写为跨境电商 + 计划岗。本岗是**计划岗不是采购执行岗**，按与画像的相关度过滤——不是所有题库题都往这场引。口播素材见 [[跨境采购面试-案例演练稿]]。

| 情景题 | 来源题库 | 对应画像 | 出现概率 |
|--------|---------|---------|---------|
| 供应商交期一拖再拖，快断货了怎么办 | 情景题·交付情景 | ①⑤ | ★★★ 高——计划岗核心场景 |
| 独家供应商坐地起价 / 依赖失控 | 情景题·垄断情景 | ①⑥ | ★★ 中——直接接入你的案例 1 |
| 如何开发和评估一家新供应商 | 能力题·供应商开发 | ① | ★★ 中低——JD 提"协调供应商"，可能追问 |
| 报价合理性 / "这个价格做不了" | 情景题·价格情景 + 能力题·成本 | — | ★ 低——JD 无降本职责，备骨架即可 |

**S1 交付情景（跨境计划岗版）⭐ 必备**：供应商交期一拖再拖，产品快断货。
四步改写：① **定位根因**——原材料没到 / 产能被别的大单挤占 / 质量返工，根因不同应对完全不同；② **算断货时间窗**——盘在库（FBA 在库可售天数）+ 在途（海运/空派头程），算清「还能卖几天」——跨境语境下断货不只是丢销量，**直接伤 listing 排名和广告权重**，恢复期更长；③ **分层预案**——工厂侧分批交货先发一部分、物流侧空派/快递加急补、**计划侧独有的第三招：协调运营放缓销售速度**（降广告预算/收优惠券），用运营节奏给供应链争取时间——这一招最能体现「计划岗的跨部门价值」；④ **跨部门同一份风险清单**（运营/采购/物流对齐同一张表）。
**收口**：「交期问题拼的是定位根因的速度和预案的厚度；而计划岗的价值是让这种事越来越少——我的缺货预警机制（案例 5）就是把救火变防火。」
**与已有答案的衔接**：Q2/Q3 讲「平时怎么防」，这道题答「真出了怎么办」——先用预警机制把风险前置，救火是最后防线。

**S2 垄断/独家情景**：直接调用案例 1 口播稿（[[跨境采购面试-案例演练稿]] 案例 ①）——你亲历过独家供应商劣化（费用高、体积误差 38%、两次查验退运）→ 展会寻源引入 B/C 两家 → 区域分工 + 口径谈判 → 费用 −30%、误差 13.8%。
**框架补充（题库理论层）**：事前布局三件套——双源储备（第二家量小也要养着）、合同锁价（涨价触发条件/涨幅上限）、真涨价时拿「替代方案 + 长期量 + 账期」重谈。
**收口金句**：「独家不是不能有，是不能没有对冲。」

**S3 供应商开发评估（低概率，备骨架）**：定准入门槛 → 寻源预筛 → 多维评估（产能/质量/交付/成本/经营风险）→ 打样试单验证 → 导入后持续跟进。你的素材：案例 1 的展会寻源 + 准入口径谈判，落点「重点不是把供应商找进来，而是证明他能持续稳定满足要求」。

**S4 价格情景（概率最低，只记骨架）**：要报价结构拆成本 → 找筹码（账期/锁量/增量）→ 历史数据对账。金句：「价格是拆出来、换出来、算出来的，不是压出来的。」被问到再展开，不主动引到降本话题。

## 五、反问清单（定制火蛋版）

1. 这个岗位是**新增**还是补缺？供应链/计划团队几个人，向谁汇报？
2. 目前补货计划靠什么系统或表格？ERP 用的是什么？
3. 库存考核指标怎么定：周转天数、售罄率、断货率，哪个优先？
4. 美国/日本/欧洲三个站点的业务占比？哪个增长最快？（决定工作重心）
5. 头程物流是自己主导还是货代主导？美国线走海运时效大概多久？
6. 大促季（Prime Day/黑五）的备战节奏大概什么样？
