## 一句话总结

**写好 Prompt 的终极心法只有两个字：压缩。** 一本书讲一个词（《定位》314 页只讲"定位"），你脑子里装下这个词，就装下了整本书；对 AI 也一样——说准一个词（如"尼采的生命意志"），就能让大模型展开巨量内容。"汉语新解"那种看起来炫技的 Lisp 写法，核心不是语言，而是被极致压缩的几个词。**你脑子里的知识，永远决定着你用 AI 的上限。**

## 背景：消失半年的李继刚

- 李继刚 2024 年 8-11 月写出数百个流传各大社区的 Prompt（"公文笔杆子"刷屏），元旦后突然消失

- 作者约了 1 个半月，在望京聚宝源边吃涮肉边聊

## 核心概念：压缩

### 消失的半年去干嘛了？——读书

- 从研究生起读 13 年，曾每年 50~100 本，但都是**工具书/畅销书**
- 读得越多越发现：这些书只在特定场景解决特定细分问题，"攒了大量工具箱，困惑反而越来越多"
- 转读哲学（先东方后西方），速度降到一个**月一本**

### 压缩 = 用一本书讲一个词

- 哲学书往往用厚厚一本讲一个词，这个过程就是**压缩**
- 例：营销书《定位》整本 314 页只讲一个词——"如何占领用户心智"
- 李继刚发现：跟大模型对话，**也能用一个词开启整个解压过程**。跟 Claude 说"尼采的生命意志"，Claude 直接展开讨论——"他不需要说一句话去表达自己的思想，只需要说准这个词"

### 极致压缩的写法诞生了"汉语新解"

```swift
;; 用途: 将一个汉语词汇进行全新角度的解释
(defun 新汉语老师 ()
  "你是年轻人,批判现实,思考深刻,语言风趣"
  (风格 . ("Oscar Wilde" "鲁迅" "林语堂"))
  (表达 . 隐喻)
  (批判 . 讽刺幽默))

(defun 汉语新解 (用户输入)
  (let (解释 (一句话表达 (隐喻 (一针见血 (辛辣讽刺 (抓住本质 用户输入))))))
    (few-shots (委婉 . "刺向他人时, 决定在剑刃上撒上止痛药。"))
    (SVG-Card 解释)))
```

> 核心不是 SVG 卡片样式，而是文案被压缩成的几个词：**隐喻、一针见血、辛辣讽刺、抓住本质**。
> 新 Prompt"类比之弓"同样压缩成四个词：**本质内核、模式知觉、同构外推、精准概括**——都来自他读过的一本书。

## 为什么用 Lisp 写 Prompt（是真有用还是炫技？）

李继刚的回答："在极致压缩成词的理念下，我能用什么语言来清晰表达我的想法？那当然就是 Lisp。"

- Lisp 诞生于 1958 年，**世界第二古老的语言，而且专门为 AI 而设计**
- 李继刚用了十年 Emacs（配置语言就是 Lisp），虽然不会写，但"看了 10 年，怎么也能学着跑两步"
- **真正核心不是用什么语言，而是那几个被极致压缩的词**——翻译成 Markdown、Python 是一样的
- "真正重要的，永远是自己的思想。思想，决定一切。"

## 对 Prompt 框架的批评

- 去年火过各种三字母/四字母框架（作者自己早年也写过 CRISPE），李继刚认为"他们跑偏了"
- 写 Prompt 的技巧性东西就那三五招：指定角色、Few-shots 示例、CoT 思维链、情绪勒索
- 本质是什么？**"想象对面坐了一个人，我要塑造一个角色，让这个角色活过来，去做一个指定的动作"**
- 框架 = 学车的辅助小双轮，让你从 0 到 1 不翻车；但"当你越想跑起来，它越是个限制，只有扔掉它，才能天高任鸟飞"
- **Read in. Prompt out.**——你读进去的东西，决定你 Prompt 出来的质量

---

## 能写好 Prompt 的人具备什么属性：Prompt Engineer

"谜底就在谜面上"：
- Prompt = 提示、表达（写作思维）；Engineer = 工程师（编程思维）
- 编程语言的脉络：二进制 → 汇编 → C → C++/Java/Python，两条清晰主线——①越来越接近自然语言，②程序员群体越来越大。推演下去**必然到自然语言编程**：人人都是程序员，大模型就是编译器
- 今年他更感觉 Prompt 像写作：脑子里有东西需要压缩后清晰表达，讲究篇章布局
- **正确答案是两者的交集**：既要有理性数学的编程思维，又要会写作的感性表达思维——两者合并，就是 Prompt Engineer。复盘身边写 Prompt 好的人，确实既懂编程、又常读书写作

## 结尾：20 年留一句话

李继刚说这辈子最大幸运是 60 岁那天死掉——"只有给自己画一个终点，才能知止而后有定心"。给自己留 20 年，做一件事：**给这个世界最后留下一句话**。哥白尼留下"地球绕着太阳转"，牛顿留下万有引力公式，他要留一句专属于他极致压缩的话。
